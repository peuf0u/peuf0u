**Things I made**

- [muse](https://github.com/peuf0u/muse) is a looper for jamming: four synced loop tracks, a drummer that follows them and a guitar amp that runs Neural Amp Modeler captures. C++ and JUCE.
- [simsquad](https://github.com/peuf0u/simsquad) spins up iOS simulators and Android emulators so QA can run on several devices at once. `brew install peuf0u/tap/simsquad`
- [simsquad-pilot](https://github.com/peuf0u/simsquad-pilot) lets a coding agent test a feature on those devices and report back with screenshots.
- [fastlane-plugin-poesie](https://github.com/peuf0u/fastlane-plugin-poesie) pulls translations from POEditor in your fastlane lane. 20k+ downloads on RubyGems.
- [neumorphic-resume](https://github.com/peuf0u/neumorphic-resume) is my CV as a SwiftUI app, mostly an excuse to play with animations.
- [Lobby](https://github.com/peuf0u/Lobby) is a navigation concept built with UIStackView.
